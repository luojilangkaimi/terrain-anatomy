### 16:08 · 第 2 步：新增进阶分析算法（纯函数）✅

全部**新增**在 `terrain.js` / `hydro.js` 的命名空间里，原有 5 个冻结签名不动。

| 函数 | 作用 | AOI1 | AOI2 |
|---|---|---|---|
| `Terrain.landform(z,w,h,{radius_m})` | 地貌分类：2 km 窗口起伏度，按李炳元等（2008）阈值 30/200/500/1000/2500 m 分 6 类 | 203 ms；平原 11.5%、丘陵 41.4%、小起伏山地 44.2%、中起伏 2.9% | 349 ms；小起伏 14.8%、中起伏 52.9%、大起伏 31.0% |
| `Terrain.flatWater(z,w,h,minKm2)` | 平坦水面：3×3 完全水平的连片区 ≥ 0.5 km² | 滇池 51.87 km²（1886.0 m）、松华坝水库 1.54 km²（1947.5 m） | 无 |
| `Terrain.viewshed(z,w,h,ox,oy,{observer_h})` | 视域：射线到外围每格，含地球曲率 + 折射 k=0.13，观察高 1.7 m | 46–60 ms；最高峰可见 25.3% | 68–91 ms；最高峰可见 3.9% |
| `Terrain.zonalStats(z,w,h,mask,slope)` | 区内高程/坡度统计 + 面积—高程曲线 + 面高积分 HI | — | — |
| `Hydro.flowPath(dir,w,h,ix,iy)` | 水往哪流：沿流向追到出口 | 中心点 23.45 km | 89.51 km |
| `Hydro.strahler(dir,river,w,h)` | Strahler 河流分级 | 22 ms，最高 5 级 | 18 ms，最高 5 级 |
| `Hydro.longestRiver(dir,w,h)` | 最长河（逐格最长上游流程 + 回溯） | 52.42 km | 199.83 km |
| `Hydro.steepestReach(z,dir,river,w,h,1000)` | 最陡河段（沿流向 1 km 平均比降最大） | 36.1% | 94.2% |

**验证**

- 起伏度：随机 300 点与暴力窗口计算对比，0 个不符（滑动窗口用单调队列，O(n)，与窗口大小无关）。
- 最长河：回溯路径逐步核对都沿 `dir` 走。
- 视域：射线未覆盖格数 0。
- **原有水文输出未受影响**：`computeHydro` 的 filled / dir / acc 三个数组 MD5 与改动前完全一致（AOI1 `dc350174ed / 4e4dde5d34 / 49d57ed59a`，AOI2 `757a688c15 / 5a1c30018d / 68653a0fa3`）。

### 16:15 · 第 3 步：界面重做、进阶功能接入、回归通过 ✅（v2 交付）

**修掉的演示风险**：二维划流域改为先吸附到河道（同一位置由「0.0 km²」变为 17.0 km²）；高程显示原生值两位小数；剖面加距离与高程刻度、垂直夸大标注，并自动抽 10 点与原生值核对（10/10）；三维提示与角标不再重叠；窄屏（< 1000 px）改为上下堆叠。

**新功能**：地貌分类图层、视域分析（68 ms）、水往哪流（默认单击即追踪）、Strahler 河网分级着色、水面识别（滇池湖面不再画直线河道）、流域详情卡（出口高程、高差、平均坡度、主河道级别、面高积分 HI + 面积—高程曲线）、兴趣点挑战（最高峰 / 最低点 / 最大流域 / 最长河 / 最陡河段 / 最大水面，一键定位）、二维图层同步贴到三维、经纬网、出版级导出（标题、图例、比例尺、指北针、经纬网、分析摘要、数据与方法、示意图声明）、加载进度分步显示、图层淡入、视图飞行动画、快捷键与帮助弹窗。

**回归**：AOI1 / AOI2 自检全部通过（坡度均值、分箱差、上坡 0 / 越界 0、内部汇 0）；控制台无报错；原水文输出 MD5 未变。
**修掉的性能问题**：半透明面板的 `backdrop-filter` 在软件渲染下让每帧耗时 180 ms，已去掉，现 16 ms/帧（集显同样受益）。

**未验证**：演示机真机；三维工具栏在 1440 宽下会折成两行（不影响使用）。
