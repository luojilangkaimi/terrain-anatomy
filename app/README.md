### 给成员三的接入点

只要 `js/terrain.js` 与 `js/hydro.js` 出现，`ui.js` 会自动加载，无需改任何外壳代码。

- `Terrain.slopeAspect(z, w, h, dx_m, dy_m) -> {slope, aspect}`
- `Terrain.profile(z, w, h, x0, y0, x1, y1) -> {pts:[{d_km,z}], len_km}`
- `Hydro.computeHydro(z, w, h) -> {filled, dir, acc}`
- `Hydro.riverMask(acc, w, h, thr)` — `thr` 单位是**上游格数**
- `Hydro.watershed(dir, w, h, ix, iy) -> {mask, area_km2, outlet}`

### 三维接入（已改为直接挂载，不再用 iframe）

`index.html` 里脚本顺序固定：`three.min.js → palette.js → loader.js → orbit.js → render3d.js → render2d.js → ui.js`。

外壳在切到「三维沙盘」时调用：

```js
Render3D.mount3D(el, { z: App.data.z, meta: App.data.meta, ve: 2, onPick: App.pick3D });
```

`z` 与 2D 共用同一个 `Float32Array`，不复制、不二次请求。切 AOI 时自动重挂并释放旧 WebGL 资源。三维单击走 `App.pick3D`：`snapOutlet → watershed → setOverlay`，与 2D 共用同一份水文结果。

2D/3D 色带由 `palette.js` 同时挂在 `window.RAMP_HEX` 与 `window.Palette`，`Render3D.info().paletteFrom` 可自查是否生效。

### 重要：D8 方向编码约定（成员三必读）

`Hydro.d8()` 返回的 `Int8Array` 必须用下面这套编码，否则流域与河流会连错、自检会报「上坡流向」：

| 值 | 方向 | 行列增量 (dr, dc) |
|---|---|---|
| 0 | 东 | (0, +1) |
| 1 | 东南 | (+1, +1) |
| 2 | 南 | (+1, 0) |
| 3 | 西南 | (+1, -1) |
| 4 | 西 | (0, -1) |
| 5 | 西北 | (-1, -1) |
| 6 | 北 | (-1, 0) |
| 7 | 东北 | (-1, +1) |
| -1 | 出口 / 汇 | — |

`dr` 为正表示向**南**（行号增大）。

## 阶段 4 · 三维集成（成员二 → 成员一）✅

`render3d.js`、`orbit.js` 已接进主页面，`view3d.html` 保留为三级降级用。原来的 iframe 方案已删除，改为同容器直接挂载，`z` 数组与 2D 共享。

### 实测

| 项 | 结果 |
|---|---|
| 渲染 | 512×439 网格、225,720 顶点、构建 261 ms |
| 色带 | `paletteFrom = palette.js RAMP_HEX`，2D/3D 同一套 |
| 垂直夸大 | ×2 → ×4 实时生效，角标同步 |
| 视角 | 俯视/斜视切换、环绕（实测 61 fps 时读数正常） |
| 河网叠加 | 蓝色树枝状河网正确贴合地表 |
| 三维点选 | `onPick → snapOutlet → watershed` 叠加橙色流域并更新面板 |
| 截图 | `Render3D.screenshot()` 返回有效 PNG dataURL |

### 这一阶段修掉的问题

1. `palette.js` 只挂了 `window.Palette`，`render3d.js` 读的是 `window.RAMP_HEX` → 三维一直用内置色带，两套配色。已补全局导出。
2. 浏览器把旧 JS 缓存住，改了 `palette.js` 仍跑旧代码 → 给所有本地脚本加 `?v=1`，改代码后仍需 `Ctrl+Shift+R`。
3. 原 iframe 方案每次切 tab 都重新 `fetch` 数据 → 改为共享同一个 `z`。
4. 三维面板的 `#fps3d` 一直是「—」→ 加了 800 ms 轮询（按需渲染，静止时本就为 0）。

### 已知限制（当前）

1. 二维点选要求**按下后几乎不移动**（位移 > 4 px 判为平移），演示时不要拖。
2. 三维按需渲染，静止时 fps 显示为「—」，属设计行为，不是卡死。
3. 底图不贴卫星影像（题二切片与 AOI 不重叠），用高程色带 + 坡度阴影。
4. 浏览器直读 GeoTIFF 未做，用预转换二进制。
5. 三维网格 512 段为默认；演示机若低于 30 fps，改 `mount3D(el, {segments: 256})`。
